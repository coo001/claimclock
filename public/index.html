Local live mode (optional)

      
To analyze any answer of your own, run this repository on your computer and configure your own Tavily key and a local Bifrost gateway (Gemini provider). Keys are read only from the server's .env and are never sent to the browser. See the README for detailed steps.

      
Path: browser → local backend → Tavily / local backend → Bifrost (localhost) → Gemini · per input, at most 5 Gemini calls and 8 Tavily calls
